# Pretrained Models and Weight Sources Used in BaiZe

| Model | Official Repository / Weight Source |
|---|---|
| **scGPT (whole-human)** | [Official code repository](https://github.com/bowang-lab/scGPT) · [Whole-human pretrained weights (Google Drive)](https://drive.google.com/drive/folders/1oWh_-ZRdhtoGQ2Fw24HP41FgLoomVo-y?usp=sharing) · [scGPT-human weights (Hugging Face)](https://huggingface.co/wanglab/scGPT-human/tree/main) |
| **Geneformer** | [Official model repository and pretrained weights (Hugging Face)](https://huggingface.co/ctheodoris/Geneformer/tree/main) |
| **UCE (Universal Cell Embedding)** | [Official code repository](https://github.com/snap-stanford/uce) · [Official pretrained model files (Figshare)](https://figshare.com/articles/dataset/Universal_Cell_Embedding_Model_Files/24320806) |
| **scFoundation** | [Official code repository](https://github.com/biomap-research/scFoundation) · [Official weight download instructions](https://github.com/biomap-research/scFoundation/blob/main/model/README.md) · [Model weight directory (SharePoint)](https://hopebio2020.sharepoint.com/:f:/s/PublicSharedfiles/IgBlEJ72TBE5Q76AmgXbgjXiAR69fzcrgzqgUYdSThPLrqk) |
| **scGen** | [Official code repository](https://github.com/theislab/scgen) (the public URL for the specific checkpoint used in our comparison remains to be verified) |
| **GEARS** | [Official code repository](https://github.com/snap-stanford/GEARS) (the public URL for the specific checkpoint used in our comparison remains to be verified) |
| **MorphDiff** | [Official code repository](https://github.com/biomap-research/MorphDiff). **The pretrained weights used in this study were obtained directly from the original authors by email. These weights are not publicly available and may not be redistributed; therefore, no weight download link is provided here.** |
| **Qwen3-8B (BaiZe-Agent)** | [Official pretrained model repository (Hugging Face)](https://huggingface.co/Qwen/Qwen3-8B/tree/main) |

**Note:** The **whole-human** version of scGPT was used. UCE and scFoundation were both included in the comparison experiments conducted in this study. Beyond these confirmed details, this list does not assume any specific checkpoint version for other models.
