# BaiZe reviewer reproducibility materials

This folder contains supporting documentation and reviewer-oriented demonstrations for the BaiZe manuscript.

- [Adamson Perturb-seq reviewer demo](Adamson/README.md): tested local smoke-test workflow, English training and evaluation launchers, recorded sample metrics, and environment information.
- [Adamson publication status](Adamson/PUBLICATION_STATUS.md): public artifacts still required before this example can run from a fresh clone.
- [Pretrained model sources](PRETRAINED_MODELS.md): upstream model repositories, checkpoint sources, and access limitations.

**Important:** The Adamson demo is a lightweight *software smoke test*, not a reproduction of Figure 2b's reported quantitative results. Until its dataset, lightweight checkpoint, and exact tested source are published and a clean-clone test succeeds, the public GitHub folder is not yet a standalone runnable package.
